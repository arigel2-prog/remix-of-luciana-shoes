# Remix of Luciana Shoes

Need a system for taking the orders from my store clients before the season. Then need a way to generate order confirmations to send to the clients for approval and make sure we got it right. 3. Need a way to submit those orders to my over seas factory, with their specific descriptions names. 4. Need to cross check their promo invoice to make sure they got the orders right according to what the customer gave us in the store. 5. Need a way to generate packing list and imlnvoices to the clients. 6. Need a dashboard to for the collections of the money
